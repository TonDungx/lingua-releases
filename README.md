# Lingua — bản phát hành

Kho này chỉ chứa **file cài đặt (APK)** của Lingua — app học tiếng Anh và
tiếng Trung, chạy hoàn toàn offline. Mã nguồn không nằm ở đây.

## Tải về

Vào mục [**Releases**](../../releases/latest) rồi chọn một file:

| File | Dùng cho | Dung lượng |
|---|---|---|
| `Lingua-...-universal.apk` | mọi máy, chắc ăn nhất | ~59 MB |
| `Lingua-...-arm64-v8a.apk` | hầu hết điện thoại đời mới | ~23 MB |
| `Lingua-...-armeabi-v7a.apk` | máy cũ 32-bit | ~21 MB |

## Cài đặt

1. Mở link trên điện thoại, tải file `.apk`.
2. Mở file vừa tải. Android sẽ hỏi quyền cài ứng dụng từ nguồn ngoài Play Store
   — chọn **Cho phép** cho trình duyệt đang dùng, rồi cài.

App không tự tải và không tự cài bản mới; nó chỉ đọc một file JSON để báo có
bản mới và đưa link cho bạn.
